# AI-Worker App - Design Context

## Users
- **Primary**: Business users and non-technical users
- **Context**: Desktop workspace usage, likely professional/productivity context
- **Job to be done**: Voice-first AI assistance with MCP integration for workflow automation

## Brand Personality
- **Voice**: Professional & efficient
- **Emotional goals**: Confidence, clarity, trustworthiness
- **Key trait**: Approachable despite technical complexity (since target is non-tech users)

## Aesthetic Direction
- **Visual tone**: Clean, professional, no-nonsense
- **Anti-references**: Must NOT look like generic AI assistants (ChatGPT, Claude, Gemini style)
- **Theme**: Both light and dark mode support

## Design Principles
1. **Clarity over cleverness** - Non-tech users need intuitive, obvious interactions
2. **Professional trust** - The UI should inspire confidence, not feel like a "tech demo"
3. **Efficient workflows** - Every interaction should feel purposeful, not decorative
4. **Accessibility first** - Since serving non-tech users, assume lower tech literacy
5. **Distinctive identity** - Avoid AI slop aesthetic; have a unique visual language
