# Research Prompt: AI-Worker MCP Use Cases

Copy and paste this prompt into an AI assistant (like ChatGPT-4o, Claude 3.5 Sonnet, or Perplexity) to discover deep-dive use cases and personas for your application.

---

### The Prompt

```markdown
I am developing an application called "AI-Worker," and I need to conduct deep research into Model Context Protocol (MCP) use cases, specialized user personas, and a prioritized tool-integration roadmap.

**Application Identity & Key Features:**
1. **Core:** A desktop-first workspace built on Electron/React.
2. **Voice-First:** Integrated speech-to-text (Vosk) for hands-free interaction.
3. **Connectivity:** Native WhatsApp integration used as a bidirectional notification and command channel (the AI can notify the user on WhatsApp, and the user can reply back to control the desktop agent).
4. **Browser Power:** Integrated Playwright/Puppeteer support for deep browser automation (web scraping, UI interaction, form filling).
5. **Tooling:** Full support for Model Context Protocol (MCP) to connect the agent to external APIs and local filesystem resources.
6. **Memory:** Persistent context and "memory-reflection" based on previous interactions.

**The Mission:**
Based on this specific architecture, please perform a deep-dive research analysis to identify:

1. **Top 5 "High-Impact" User Personas:** Go beyond just "Student" or "Professional." Define specialized profiles (e.g., "The Freelance Legal Clerk," "The Data-Driven E-commerce Manager," "The Academic Thesis Researcher") and explain why the voice/WhatsApp/Playwright combination is a "killer feature" for them.
2. **5 Advanced "Agentic Loop" Use Cases per Persona:** Describe automated workflows where the agent uses the local filesystem, browser automation (Playwright), and a third-party MCP server (like GitHub, HubSpot, or Zotero) to finish a complex task autonomously.
3. ** prioritized MCP Server Roadmap:** Categorize which MCP servers are "Critical" (must-have), "Strategic" (competitive advantage), and "Extended" (nice-to-have) for this specific app.
4. **The "WhatsApp Loop" Innovation:** Suggest 3 unique ways the WhatsApp integration can be used to solve complex "Human-in-the-loop" problems (e.g., the agent encounters a captcha in the browser, pings the user on WhatsApp with a screenshot, user replies with the solution, and the agent continues).

**Output Format:**
- Use a structured, professional report format.
- Use tables for the tool roadmap.
- Provide clear, actionable bullet points for the use cases.
```
